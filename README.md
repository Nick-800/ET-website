# Blueprint Digital / ET-Group

This repository contains the ET-Group marketing site built with Vite, React, TypeScript and Tailwind CSS.

Getting started

1. Clone the repository:

```bash
git clone <YOUR_GIT_URL>
cd blueprint-digital
```

2. Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Project tech

- Vite
- React + TypeScript
- Tailwind CSS

Notes

- If you removed or changed dependencies, run `npm install` to refresh `package-lock.json`.
- Open issues or file edits can be made via your preferred editor or GitHub.

Replace `<YOUR_GIT_URL>` with your repository remote and adjust scripts/commands to match your workflow.
